# user stories:
- المستخدم يقوم بعملية تسجيل الدخول ( مستثمر , صاحب خدمه, صاحب مورد , مهندس )
- تغيير كلمة المرور عند فقدانها
- الزائر يمكنه رؤية الموقع بشكل عام بدون اي صلاحيه
    - رؤية الصفحة الرئيسية التي تحتوي على ( افضل المستثمرين و افضل الاراضي و المباني و اضفل الموردين وافضل مزودي الخدمات )
    - امكانية التواصل مع الدعم الفني
    - البحث عن اراضي او مباني
    - البحث عن صاحب ( مورد و خدمة )
    - رؤية الملف الشخصي لاي مستخدم بغض النظر عن صلاحيته 
    - رؤية صفحة الهبوط الخاصة بالمنصة لزيادة احتماية الاشتراك بالمنصة 
    - رؤية قسم الخدمات و قسم مزودي الخدمات بالاضافة الى المستثمرين المميزين

- المستخدم الذي يملك صلاحية مستثمر 
    - لدية صفحة شخصية لعرض تفاصيله ضمن المنصة( عامة )
    - امكانية اضافة ارض او مبنى
    -  (البحث عن اصحاب اراضي او مباني )امكانية الاستثمار في الاراضي المتاحة
    -  عرض ارض للبيع او مبنى ( هنا يجب اجراء توثيق للارض قبل عرضها )
    - بدء مشروع في احد الاراضي الخاصة به او مبنى خاص به 
    - استعراض المشاريع المفتوحه
    - لوحة تحكم بكل مشروع مفتوح( مستوى التقدم, الموارد المطلوبه, الخدمات المطلوبه, الورشات الموجوده, التقارير, التقارير المرفوعه من المشرفين )
    - البحث عن مزودي خدمات او مزودي موارد او مهندسين ( لاضافتهم في مشروع قائم )
    - صفحة التواصل مع الاشخاص
    - تقييم الخدمات

- المستخدم الذي يملك صلاحية صاحب مورد: 
    - استقبال الطلبات الواردة من المستثمرين
    - ادارة الملف الشخصي ( عام )
    - قسم اضافة الموارد التي يمكن ان يزودها ( اكثر من مورد )
    - امكانية مشاهده انشاء تواصل مع المستثمر 
    - اضافة مورد غير موجود في النظام يتم قبوله من المشرفين 
    - تلقي الاشعارات من النظام( تم قبول المورد الجديد الذي تم اقتراحة )
    - امكانية ادارة القسم المالي ( بالاعتماد على الطلبات والكميات التي تم بيعها)

- المسخدم الذي يملك صلاحية من نوع مزود خدمه:
    - استقبال الطلبات الواردة من المستثمرين
    - ادارة الملف الشخصي ( عام )
    - قسم اضافة الخدمة التي يقدمها ( اكثر من خدمه )
    - امكانية التواصل مع مستثمرين
    - اضفافة خدمة غير موجودة بشكل مسبق في النظام يتم الموافقة عليها من قبل المشرفين 
    - تلقي الاشعارات من النظام ( تم قبول الخدمه المراد اضافتها )
    - امكانية رؤية القسم المالي ( بالاعتماد على الطلبات المباعة )
